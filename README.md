# Interview Questions

Каталог вопросов для подготовки к техническим собеседованиям на React и TypeScript.

## Возможности

- Поиск с debounce 400 мс.
- Фильтрация по специализации, навыкам, сложности и рейтингу.
- Серверная пагинация с сохранением параметров в URL.
- Страница вопроса с ответами.
- Состояния загрузки и ошибки списка, страница неизвестного маршрута.
- Очистка HTML-контента ответов через DOMPurify.

## Стек

React, TypeScript, Vite, React Router, SCSS, DOMPurify, Fetch API.

## Технические решения

Устаревшие запросы отменяются при изменении параметров и переходе между страницами. Ошибка загрузки отдельного вопроса отображается пользователю.

Запросы вынесены в `src/api`, логика страниц — в пользовательские хуки. Фильтры хранятся в URL search params, поэтому ссылку на выбранный список можно сохранить или передать.

## Локальный запуск

Создайте локальный `.env.local`:

```dotenv
VITE_API_BASE_URL=https://api.yeatwork.ru
```

```bash
npm ci
npm run dev
```

`npm run build` — сборка, `npm run lint` — проверка кода.


## Ограничения

Backend не входит в репозиторий. Для работы нужен доступный внешний API. Отдельный набор автоматических тестов и GitHub Actions workflow не добавлены.

Это отдельный компактный пример работы с Fetch API и хуками; расширенное приложение с коллекциями и тренажёром находится в [collection-list](https://github.com/Milo78k/collection-list).
